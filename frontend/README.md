# BookSwap — frontend

Интерфейс учебного приложения для обмена книгами на React + TypeScript и Vite.
Для клиентской маршрутизации используется React Router, для кнопок, полей,
переключателей, статусов, диалогов и уведомлений — Material UI.

## Запуск

Проверено на Node.js 22.22.1 и npm 9.2.0.

Из корня репозитория:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале (обычно http://localhost:5173).

## Проверки и сборка

Из папки `frontend`:

```bash
npm run lint
npm run build
```

Сборка сохраняется в `dist/`. Для её локального просмотра выполните `npm run preview`.

## Экраны и маршруты

Переходы выполняются через `Link` и `NavLink` без перезагрузки страницы.
Активный раздел выделяется в шапке, на странице книги есть ссылка на каталог.
Кнопки браузера «Назад» и «Вперёд» используют историю клиентских переходов.

| Маршрут | Компонент |
| --- | --- |
| `/` | `CatalogPage` |
| `/books/:id` | `BookPage` |
| `/reservations` | `ReservationsPage` |
| `/locations` | `LocationsPage` |
| `/statistics` | `StatisticsPage` |

Для неизвестных маршрутов и отсутствующих книг предусмотрен `NotFoundPage`.
Для размещения сборки на сервере нужно настроить возврат `index.html` для
клиентских маршрутов, например `/books/1`. Vite в режиме разработки делает это автоматически.

## Демонстрационные данные

В `src/data/demo.ts` находятся 8 книг, 3 вымышленных пункта выдачи и пользователь
Алексей. Начальные бронирования: «Мастер и Маргарита» ждёт выдачи Алексею,
«Три товарища» у него на руках, «Вино из одуванчиков» читает другой пользователь.
Одна запись книги представляет один экземпляр, закреплённый за пунктом выдачи.

В каталоге работают поиск по названию и автору, фильтры по жанру и доступности.
Фильтры записываются в URL. Если совпадений нет, можно сбросить фильтры.

Доступную книгу можно забронировать. Она появится в «Моих бронированиях», а её
статус и статистика обновятся. Отмена доступна для книг, ожидающих выдачи, и
требует подтверждения в диалоге. Книгу на руках отменить нельзя.
В деморежиме срок возврата — 14 дней с даты бронирования; начальные даты
вычисляются относительно дня открытия приложения.

Общее состояние хранится в `App.tsx`. При переходах между экранами оно
сохраняется, при обновлении страницы сбрасывается. Backend, авторизация и
постоянное хранение данных на этом этапе не используются.

## Проверка вручную

1. Запустите `npm run dev` и откройте адрес из терминала.
2. В каталоге найдите книгу по автору, выберите жанр и включите «Только доступные».
3. Откройте доступную книгу и забронируйте её.
4. Перейдите в «Мои бронирования» и проверьте новую запись и срок возврата.
5. Проверьте изменение счётчиков в «Статистике» и «Местах выдачи».
6. Отмените новую бронь через диалог и проверьте, что книга снова доступна.
7. Проверьте «Назад»/«Вперёд», прямой адрес `/books/1` и неизвестный `/books/999`.
8. Проверьте страницы на узком экране. Сохраните скриншоты пяти экранов вручную
   в `docs/screenshots/` в корне репозитория.

Тестовые библиотеки не устанавливаются: для текущего этапа используются
проверка сборки и ручной просмотр приложения.
