# BookSwap — frontend

Начальный каркас учебного приложения на React + TypeScript, созданный через Vite.

## Запуск

Проверено на Node.js 22.22.1 и npm 9.2.0.

Из корня репозитория:

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале (обычно http://localhost:5173).

## Проверки и сборка

Из папки `frontend`:

```bash
npm run lint
npm run build
```

Сборка сохраняется в `dist/`. Для её локального просмотра выполните `npm run preview`.

## Структура

```text
src/
├── components/
│   └── Header.tsx           # Общая шапка приложения
├── data/                   # Место для демонстрационных данных
├── pages/
│   ├── BookPage.tsx         # Информация о книге
│   ├── CatalogPage.tsx      # Каталог книг
│   ├── LocationsPage.tsx    # Места выдачи
│   ├── ReservationsPage.tsx # Мои бронирования
│   └── StatisticsPage.tsx   # Статистика
├── types/                  # Место для общих типов предметной области
├── App.tsx                 # Компоновка приложения
├── App.css                 # Стили компоновки и страниц
├── index.css               # Глобальные стили
└── main.tsx                # Точка входа React
```

Папки `data` и `types` сохранены с помощью `.gitkeep`, чтобы они попадали в Git до добавления файлов.
