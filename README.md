# fullstack_bookswap

BookSwap — веб-приложение для обмена книгами между пользователями.

## Назначение проекта

Приложение предназначено для поиска и бронирования книг, доступных для обмена.

Пользователь может просматривать каталог книг, получать информацию о выбранной книге, бронировать книги, следить за сроками возврата и выбирать удобное место выдачи.

Также в приложении предусмотрена простая статистика по книгам и бронированиям.

## Основные пользовательские сценарии

1. Просмотр каталога доступных книг.
2. Поиск интересующей книги.
3. Просмотр подробной информации о книге.
4. Бронирование доступной книги.
5. Просмотр своих бронирований.
6. Просмотр срока возврата книги.
7. Просмотр доступных мест выдачи.
8. Просмотр статистики сервиса.

## Основные экраны

### Каталог книг
Отображает список доступных книг и позволяет перейти к подробной информации о выбранной книге.

### Страница книги
Содержит название, автора, жанр, статус книги, место выдачи и возможность бронирования.

### Мои бронирования
Отображает забронированные пользователем книги, даты бронирования и сроки возврата.

### Места выдачи
Содержит список доступных пунктов, в которых можно получить или вернуть книгу.

### Статистика
Отображает простую информацию о количестве книг, доступных книгах и активных бронированиях.

## Запуск frontend

Проверено на Node.js 22.22.1 и npm 9.2.0.

```bash
cd frontend
npm ci
npm run dev
```

Откройте адрес из вывода Vite в терминале (обычно http://localhost:5173).

Проверка кода: `npm run lint`. Проверка TypeScript и сборка: `npm run build`.
Команды выполняются из папки `frontend`.

## Текущее состояние

Реализованы пять экранов на React + TypeScript с клиентской маршрутизацией
React Router и компонентами Material UI:

- `/` — каталог с поиском по названию и автору, фильтрами по жанру и доступности;
- `/books/:id` — описание книги, статус, пункт выдачи и бронирование;
- `/reservations` — бронирования пользователя, сроки возврата и отмена брони;
- `/locations` — пункты выдачи, адреса, часы работы и количество доступных книг;
- `/statistics` — количество книг, бронирований, пунктов выдачи и распределение по жанрам.

Неизвестные адреса и отсутствующие книги показывают экран с возвратом в каталог.
Вёрстка адаптируется к ширине экрана.

Демонстрационные данные: 8 книг, 3 вымышленных пункта выдачи и 3 активных
бронирования, из которых 2 принадлежат демонстрационному пользователю Алексею.
Бронирование и отмена обновляют данные на всех экранах без перезагрузки.
Изменения хранятся в памяти React и сбрасываются при обновлении страницы.
Серверная часть и авторизация будут добавлены в следующих лабораторных.

Скриншоты экранов сохраняются вручную в `docs/screenshots/`.

Подробная структура описана в [frontend/README.md](frontend/README.md).
